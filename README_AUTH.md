# ورود و سطح دسترسی

این نسخه ورود با شماره موبایل و رمز عبور دارد.

## ادمین
مقادیر ادمین در `.env`:
- `ADMIN_PHONE=09000000000`
- `ADMIN_PASSWORD=Admin@12345`

شماره و رمز را قبل از استفاده تغییر دهید. ادمین همه راکب‌ها، رانشیت‌ها، آمار، خروجی و پشتیبان‌گیری را می‌بیند.

## راکب
هر راکب در صفحه «راکب‌ها» با شماره موبایل و رمز عبور ساخته می‌شود. بعد از ورود، فقط رانشیت‌ها و مرسوله‌های متعلق به خودش قابل مشاهده/ویرایش است.

## نصب
بعد از جایگزین کردن پروژه:
1. `.env` را تنظیم کنید.
2. `setup-windows.bat` را اجرا کنید.
3. برای اجرا `start.bat` یا `run-dev.bat` را بزنید.
4. صفحه ورود در `http://localhost:3090/login` باز می‌شود.

حساب‌های نمونه seed:
- 09121234567 / 123456
- 09123334444 / 123456
- 09125556666 / 123456
