# Cargo Manager v1.1 — Desktop + Local Network

نرم‌افزار مدیریت راکب، رانشیت و بارکد با دیتابیس مرکزی SQLite، رابط فارسی RTL و امکان استفاده همزمان چند کامپیوتر در یک شبکه محلی.

## امکانات

- مدیریت راکب‌ها
- رانشیت NDX و SAPA Post
- اسکن بارکد USB / Keyboard Wedge
- ثبت مرسوله عادی و برگشتی
- جلوگیری از بارکد تکراری
- تاریخ و ساعت خودکار و نمایش شمسی
- جستجوی پیشرفته
- Backup / Restore
- رابط جدید Responsive، انیمیشنی و مناسب اپراتورهای غیرحرفه‌ای
- همگام‌سازی زنده تغییرات داخل شبکه با Server-Sent Events
- نمایش IP و Port کامپیوتر اصلی داخل خود برنامه
- Electron برای نسخه Windows

## معماری شبکه

فقط **کامپیوتر اصلی** برنامه/سرور و دیتابیس را اجرا می‌کند:

```text
Computer A (Host / Desktop App)
  Cargo Manager + SQLite
  192.168.1.10:3090
           |
     Local Network
      /          \
Computer B      Computer C
Browser         Browser
```

کامپیوترهای دوم و سوم هیچ دیتابیس جداگانه‌ای ندارند. همه درخواست‌ها روی دیتابیس کامپیوتر اصلی انجام می‌شود، بنابراین داده‌ها یکپارچه هستند.

## نصب اولیه

روی کامپیوتر اصلی:

```bat
setup-windows.bat
```

برای اجرای نسخه توسعه/لوکال:

```bat
run-dev.bat
```

سپس روی کامپیوتر اصلی باز کنید:

```text
http://localhost:3090
```

داخل منوی سمت راست برنامه، IP شبکه به شکل زیر نمایش داده می‌شود:

```text
http://192.168.1.10:3090
```

روی کامپیوتر دوم که به همان Router/Wi-Fi/LAN وصل است، همین آدرس را در Chrome/Edge وارد کنید.

## Windows Firewall

اگر کامپیوتر دوم نتوانست صفحه را باز کند، روی کامپیوتر اصلی فایل زیر را با **Run as administrator** اجرا کنید:

```text
allow-network-windows.bat
```

این فایل فقط TCP Port 3090 را روی شبکه‌های Private در Windows Firewall باز می‌کند.

> اگر Router قابلیت AP/Client Isolation داشته باشد باید غیرفعال باشد تا دستگاه‌های داخل Wi-Fi بتوانند یکدیگر را ببینند.

## همگام‌سازی زنده

برنامه از `/api/events` برای اتصال Real-time استفاده می‌کند. وقتی روی یک دستگاه راکب، رانشیت، بارکد یا وضعیت مرسوله تغییر کند، دستگاه‌های دیگر بدون Refresh دستی اطلاعات خود را دوباره می‌خوانند.

SQLite همچنان فقط روی Host باز می‌شود؛ Clientها مستقیم فایل دیتابیس را Share نمی‌کنند. این روش برای شبکه محلی بسیار امن‌تر و پایدارتر از قرار دادن فایل `.db` روی Network Share است.

## Build نسخه Windows

```bat
build-windows.bat
```

خروجی در:

```text
dist-electron/
```

نسخه Electron نیز روی Port 3090 شروع می‌کند؛ اگر 3090 اشغال باشد، یکی از Portهای بعدی را انتخاب می‌کند و آدرس واقعی داخل Sidebar نمایش داده می‌شود.

## نکته امنیتی

نسخه فعلی برای شبکه داخلی طراحی شده و Login ندارد؛ هر دستگاهی که به شبکه محلی دسترسی داشته باشد و IP/Port را بداند می‌تواند برنامه را باز کند. برای شبکه‌های بزرگ‌تر پیشنهاد می‌شود در نسخه بعدی Login/PIN و سطح دسترسی اپراتورها اضافه شود.
